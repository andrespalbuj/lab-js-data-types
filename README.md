# LAB IFCD0210 | Tipos de datos en JavaScript

Este repositorio contiene el ejercicio adaptado para los alumnos del certificado IFCD0210. El objetivo es practicar operaciones con cadenas, números y valores booleanos en JavaScript.

## Cómo ejecutar el ejercicio con Node.js

1. Abre una terminal.
2. Ejecuta el archivo `index.js` con Node.js:

```bash
node index.js
```

2. Observa los resultados en la terminal. El ejercicio muestra la salida con `console.log()`.

> Si no tienes Node.js instalado, descárgalo desde https://nodejs.org/ e instálalo antes de ejecutar el comando.

## Resultados esperados por iteración

- Iteración 1.1: `Fred fed Ted bread and Ted fed Fred bread`
- Iteración 1.2: `javAscripT`
- Iteración 2.1: `12.6`
- Iteración 2.2: un número entero aleatorio entre `1` y `10` (inclusive)

### Iteración 3.1 | Booleanos
- `expression1`: `false`
- `expression2`: `true`
- `expression3`: `false`
- `expression4`: `true`
- `expression5`: `true`
- `expression6`: `false`
- `expression7`: `true`

## Instrucciones del ejercicio

Todo el trabajo se realiza en el archivo `index.js`.

Para cada iteración debes:

- leer el bloque correspondiente en `index.js`
- completar el código según la descripción
- ejecutar `node index.js` desde la terminal para ver la salida

## Notas importantes

- La salida se muestra directamente en la terminal con Node.js.
- La iteración 2.2 genera un valor aleatorio, por lo que su resultado cambia cada vez que ejecutes el archivo.
